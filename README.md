# ZensaxPulse

A local-first Linux System Intelligence desktop application.

## Vision

ZensaxPulse provides detailed Linux system monitoring through a
modern neumorphic desktop interface.

## Core Principles

- Strictly local execution
- No cloud backend
- No telemetry
- No external API calls
- No runtime internet dependency
- Least-privilege system access
- Arch Linux and Ubuntu compatibility

## Planned Features

- CPU analytics
- Memory analytics
- GPU monitoring
- Storage analytics
- Network monitoring
- Process management
- Systemd service monitoring
- Hardware sensor monitoring
- Local monitoring history

## Technology

- Tauri 2
- React
- TypeScript
- Vite
- Tailwind CSS
- Rust
- Linux system interfaces

## Development

Development begins on Arch Linux.

Ubuntu and other compatible Linux distributions are additional
supported targets.
